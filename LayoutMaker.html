Using Layout Maker

A quick guide to the main things you can do here.

  • Add contentChoose an item from the Library, or drag it onto a section.
  • Preview before addingHover over a library item, preset, or element set to see its shape and content mix.
  • Select several itemsHold Ctrl on Windows or Command on Mac while selecting elements.
  • Move a groupDrag any selected element to move the selected elements together. Their order stays together.
  • Edit detailsSelect an element or section and use the Properties panel to change its text, name, size, and appearance.
  • Undo or redoUse the toolbar buttons, or press Ctrl+Z and Ctrl+Y on Windows. On Mac, use Command+Z and Command+Y.
  • Keep working laterYour current layout is saved automatically in this browser and returns when you reload.
  • Send to LucidchartWhen your layout is ready, choose Copy to Lucid and paste it into Lucidchart.
