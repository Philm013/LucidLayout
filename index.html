Lucid API

Your API key is stored locally in this browser (localStorage) and sent directly from this page to Lucid's API — no server-side proxy is used.

Image size controls how large blocks appear in Lucid. Image pixel dimensions controls the underlying exported raster resolution. Label text size affects both Copy and Send label objects.

Lucid's Standard Import supports JPEG, PNG, GIF, BMP, and TIFF images (SVGs are converted to PNG on import) — WebP is not supported, so it isn't offered here.

Need an API key? Go to lucid.app/developer, create an app, and generate an API key with the DocumentEdit grant.
