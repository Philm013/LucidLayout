Help and Shortcuts

Overview of core features, export options, and keyboard access.

Core workflow

  • Use Import to add image files, folders, or document pages.
  • Edit the grid with rows, columns, gaps, and cell size controls in the sidebar.
  • Use Auto pack and Clear and Reset Grid for layout management.
  • Use Export to copy Lucid payloads, copy a PNG preview, or download a PNG preview.
  • Use Send to Lucid after adding an API key in Settings.

Grid and tray actions

  • Click a grid slot to select it. Use inline cell actions to preview, move, replace, clear, or paste.
  • When a row or column is trimmed, removed images are staged in the Image Tray.
  • Use the tray to place staged images back into the grid or permanently remove them.
  • Use History to jump to earlier checkpoints and Exports to revisit Lucid links.

Keyboard shortcuts

  • Tab and Shift + Tab: move between controls.
  • Enter or Space on a grid slot: select the slot.
  • Arrow keys on a focused grid slot: move focus between slots.
  • M on a filled slot: press M to move that image with the keyboard.
  • Enter while move mode is active: place the selected or staged image into the focused slot.
  • Escape during move mode: cancel keyboard placement.
  • P or V on a filled slot: open image preview.
  • Escape in any dialog: close the dialog.
  • Arrow Left and Arrow Right in image preview: move between preview items.
  • Ctrl + Z: undo. Ctrl + Shift + Z or Ctrl + Y: redo.
  • Paste with a grid slot selected: paste an image from the clipboard into that slot.

Accessibility notes

  • Dialogs trap keyboard focus until closed and return focus to the button that opened them.
  • The app supports reduced-motion preferences and strong visible focus outlines.
  • Document page thumbnails expose selected state, and history checkpoints are keyboard-operable buttons.

Lucid API

Connection
Export sizing

Image size controls block size in Lucid. Pixel dimensions control raster resolution. Label text size affects Copy and Send label objects.

File optimization

Standard Import supports JPEG, PNG, GIF, BMP, and TIFF. SVGs are converted to PNG; WebP is not offered.

Need an API key? Go to lucid.app/developer, create an app, and generate an API key with the DocumentEdit grant.
